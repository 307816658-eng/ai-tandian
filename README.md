# AI 探店视频分镜与提示词工作台 (即梦 / 豆包专用)

为本地生活商家与达人定制开发的 AI 探店分镜与提示词编译器，实现“门头识图 → 爆款编剧 → 角色锚点锁定 → Seedance 物理运镜编译 → 剪映后期配音”的工业级全自动闭环。

## 核心特性
- **门头原图防乱码**：首镜（00:00-00:05）强制锁定真实门头照片作为首帧图，招牌字 100% 真实不乱码。
- **人物与场景一致性锚点**：预先生成达人白底定妆照（9:16）与店内主场景空镜图（9:16），逐镜注入人设与微动作指令，彻底终结 AI 视频换脸与跳戏。
- **5 秒黄金口播节奏**：每镜口播严格限定 16~22 个汉字，精准匹配自然语速与完播率。
- **直通剪映后期**：纯享版口播台词一键复制，支持一键导出完整 TXT 分镜脚本。
- **内置 Agnes 3.0 旗舰大脑**：后台静默运行原生多模态视觉大模型，免除手动配置 API 的繁琐操作。

## 部署说明
静态单文件架构，自动联动 Cloudflare Pages 全球 CDN 加速部署。
